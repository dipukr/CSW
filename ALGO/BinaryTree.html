Binary Tree Problems

The exercises below are ordered by increasing difficulty.

Every section gives the iterative implementation first, then the recursive one.

All snippets share the Node class and the build helper from the first section. Unless stated otherwise, examples use the 7-node sample tree built there. h is the tree height and w the width of the widest level.

Recursive versions use O(h) call-stack space. On very deep trees (tens of thousands of levels, such as a degenerate chain), prefer the iterative form to avoid a StackOverflowError.

Node structure and building a treeEasy

Each node stores a value and references to a left and a right child. A missing child is null.

Trees are built from an array in heap order: the children of index i sit at 2i + 1 and 2i + 2, and null marks a missing node.

Input: [40, 20, 70, 10, 30, 60, 90]

Output: the tree below, used as the sample in most sections.

SAMPLE TREE

Node values with their heap-order array index i; the children of i are at 2i + 1 and 2i + 2.

The iterative version creates every node first, then links each one to its children by index. The recursive version builds index i and asks itself for the subtrees at 2i + 1 and 2i + 2.

Time O(n), space O(n).

Node
public class Node {
    public int data;
    public Node left;
    public Node right;

    public Node(int data) {
        this.data = data;
    }
}
Iterative
public Node build(Integer... values) {
    if (values.length == 0 || values[0] == null)
        return null;
    var nodes = new Node[values.length];
    for (int i = 0; i < values.length; i++)
        if (values[i] != null)
            nodes[i] = new Node(values[i]);
    for (int i = 0; i < values.length; i++) {
        if (nodes[i] == null)
            continue;
        if (2 * i + 1 < values.length)
            nodes[i].left = nodes[2 * i + 1];
        if (2 * i + 2 < values.length)
            nodes[i].right = nodes[2 * i + 2];
    }
    return nodes[0];
}
Recursive
public Node build(Integer[] values, int index) {
    if (index >= values.length || values[index] == null)
        return null;
    var node = new Node(values[index]);
    node.left = build(values, 2 * index + 1);
    node.right = build(values, 2 * index + 2);
    return node;
}
Print a tree level by levelEasy

Input: the sample tree

Output:

Level 1: 40
Level 2: 20 70
Level 3: 10 30 60 90

Iterative: breadth-first search with a queue. At the start of each round, the queue holds exactly one level, so queue.size() says how many nodes to take.

Recursive: for each level number, walk the tree and collect the nodes exactly that many steps down. This is simple, but it revisits the upper levels once per level.

Time O(n) iterative, O(n·h) recursive. Space O(w) (widest level) iterative, O(h) recursive.

Iterative
public void drawLevels(Node root) {
    if (root == null)
        return;
    var queue = new ArrayDeque<Node>();
    queue.offer(root);
    int level = 1;
    while (!queue.isEmpty()) {
        var line = new StringJoiner(" ");
        for (int count = queue.size(); count > 0; count--) {
            Node node = queue.poll();
            line.add(String.valueOf(node.data));
            if (node.left != null)
                queue.offer(node.left);
            if (node.right != null)
                queue.offer(node.right);
        }
        Console.draw("Level {level}: {line}");
        level++;
    }
}
Recursive
public void drawLevels(Node root) {
    int height = height(root);
    for (int level = 1; level <= height; level++) {
        var line = new StringJoiner(" ");
        collectLevel(root, level, line);
        Console.draw("Level {level}: {line}");
    }
}

public void collectLevel(Node node, int level, StringJoiner line) {
    if (node == null)
        return;
    if (level == 1) {
        line.add(String.valueOf(node.data));
        return;
    }
    collectLevel(node.left, level - 1, line);
    collectLevel(node.right, level - 1, line);
}
Preorder traversal (LeetCode 144)Easy

Input: the sample tree

Output: [40, 20, 10, 30, 70, 60, 90]

Order: node, left, right.

The iterative version pops a node, records it, then pushes the right child before the left child, so that the left subtree comes off the stack first.

Time O(n). Extra space O(h), where h is the tree height.

Iterative
public List<Integer> preorder(Node root) {
    var result = new ArrayList<Integer>();
    if (root == null)
        return result;
    var stack = new ArrayDeque<Node>();
    stack.push(root);
    while (!stack.isEmpty()) {
        Node node = stack.pop();
        result.add(node.data);
        if (node.right != null)
            stack.push(node.right);
        if (node.left != null)
            stack.push(node.left);
    }
    return result;
}
Recursive
public List<Integer> preorder(Node root) {
    var result = new ArrayList<Integer>();
    preorder(root, result);
    return result;
}

public void preorder(Node node, List<Integer> result) {
    if (node == null)
        return;
    result.add(node.data);
    preorder(node.left, result);
    preorder(node.right, result);
}
Inorder traversal (LeetCode 94)Easy

Input: the sample tree

Output: [10, 20, 30, 40, 60, 70, 90]

Order: left, node, right. For a binary search tree, this visits the values in sorted order.

The iterative version pushes the whole left spine, then pops a node, records it, and moves to its right child. The loop continues while there is a current node or the stack is non-empty.

Time O(n). Extra space O(h).

Iterative
public List<Integer> inorder(Node root) {
    var result = new ArrayList<Integer>();
    var stack = new ArrayDeque<Node>();
    Node curr = root;
    while (curr != null || !stack.isEmpty()) {
        while (curr != null) {
            stack.push(curr);
            curr = curr.left;
        }
        curr = stack.pop();
        result.add(curr.data);
        curr = curr.right;
    }
    return result;
}
Recursive
public List<Integer> inorder(Node root) {
    var result = new ArrayList<Integer>();
    inorder(root, result);
    return result;
}

public void inorder(Node node, List<Integer> result) {
    if (node == null)
        return;
    inorder(node.left, result);
    result.add(node.data);
    inorder(node.right, result);
}
Postorder traversal (LeetCode 145)Easy

Input: the sample tree

Output: [10, 30, 20, 60, 90, 70, 40]

Order: left, right, node. A node is recorded only after both subtrees are finished.

One stack: walk left as far as possible. At the top of the stack, go right if the right subtree exists and was not just finished (prev). Otherwise record the node and pop it.

Two stacks: produce node, right, left (a mirrored preorder) onto a second stack, then pop it to reverse the order.

Time O(n). Extra space O(h) for one stack, O(n) for two.

Iterative
public List<Integer> postorder(Node root) {
    var result = new ArrayList<Integer>();
    var stack = new ArrayDeque<Node>();
    Node curr = root, prev = null;
    while (curr != null || !stack.isEmpty()) {
        if (curr != null) {
            stack.push(curr);
            curr = curr.left;
        } else if (stack.peek().right != null && stack.peek().right != prev) {
            curr = stack.peek().right;
        } else {
            prev = stack.pop();
            result.add(prev.data);
        }
    }
    return result;
}

public List<Integer> postorderTwoStacks(Node root) {
    var result = new ArrayList<Integer>();
    if (root == null)
        return result;
    var stack = new ArrayDeque<Node>();
    var output = new ArrayDeque<Node>();
    stack.push(root);
    while (!stack.isEmpty()) {
        Node node = stack.pop();
        output.push(node);
        if (node.left != null)
            stack.push(node.left);
        if (node.right != null)
            stack.push(node.right);
    }
    while (!output.isEmpty())
        result.add(output.pop().data);
    return result;
}
Recursive
public List<Integer> postorder(Node root) {
    var result = new ArrayList<Integer>();
    postorder(root, result);
    return result;
}

public void postorder(Node node, List<Integer> result) {
    if (node == null)
        return;
    postorder(node.left, result);
    postorder(node.right, result);
    result.add(node.data);
}
Level order traversal (LeetCode 102)Easy

Input: the sample tree

Output: [[40], [20, 70], [10, 30, 60, 90]]

Iterative: breadth-first search, taking queue.size() nodes per round so that each round is one level.

Recursive: depth-first search that carries the depth. The first time a depth is reached, a new list is opened for it. Left is visited before right, so each level stays in left-to-right order.

Time O(n). Extra space O(w) iterative, O(h) recursive (plus the output).

Iterative
public List<List<Integer>> levelOrder(Node root) {
    var result = new ArrayList<List<Integer>>();
    if (root == null)
        return result;
    var queue = new ArrayDeque<Node>();
    queue.offer(root);
    while (!queue.isEmpty()) {
        var level = new ArrayList<Integer>();
        for (int count = queue.size(); count > 0; count--) {
            Node node = queue.poll();
            level.add(node.data);
            if (node.left != null)
                queue.offer(node.left);
            if (node.right != null)
                queue.offer(node.right);
        }
        result.add(level);
    }
    return result;
}
Recursive
public List<List<Integer>> levelOrder(Node root) {
    var result = new ArrayList<List<Integer>>();
    levelOrder(root, 0, result);
    return result;
}

public void levelOrder(Node node, int depth, List<List<Integer>> result) {
    if (node == null)
        return;
    if (depth == result.size())
        result.add(new ArrayList<>());
    result.get(depth).add(node.data);
    levelOrder(node.left, depth + 1, result);
    levelOrder(node.right, depth + 1, result);
}
Size of a treeEasy

Input: the sample tree

Output: 7

Every node must be visited once. The recursive form reads directly as the definition: size = size(left) + size(right) + 1.

Time O(n). Extra space O(w) iterative, O(h) recursive.

Iterative
public int size(Node root) {
    if (root == null)
        return 0;
    var queue = new ArrayDeque<Node>();
    queue.offer(root);
    int count = 0;
    while (!queue.isEmpty()) {
        Node node = queue.poll();
        count++;
        if (node.left != null)
            queue.offer(node.left);
        if (node.right != null)
            queue.offer(node.right);
    }
    return count;
}
Recursive
public int size(Node root) {
    if (root == null)
        return 0;
    return size(root.left) + size(root.right) + 1;
}
Height of a tree (LeetCode 104)Easy

Input: the sample tree

Output: 3

Height here counts the nodes on the longest root-to-leaf path: an empty tree has height 0 and a single node has height 1. Some texts count edges instead, which gives one less.

Iterative: count the breadth-first rounds. Recursive: one more than the taller subtree.

Time O(n). Extra space O(w) iterative, O(h) recursive.

Iterative
public int height(Node root) {
    if (root == null)
        return 0;
    var queue = new ArrayDeque<Node>();
    queue.offer(root);
    int levels = 0;
    while (!queue.isEmpty()) {
        for (int count = queue.size(); count > 0; count--) {
            Node node = queue.poll();
            if (node.left != null)
                queue.offer(node.left);
            if (node.right != null)
                queue.offer(node.right);
        }
        levels++;
    }
    return levels;
}
Recursive
public int height(Node root) {
    if (root == null)
        return 0;
    return Math.max(height(root.left), height(root.right)) + 1;
}
Sum of all nodesEasy

Input: the sample tree

Time O(n). Extra space O(w) iterative, O(h) recursive.

Iterative
public int treeSum(Node root) {
    int sum = 0;
    if (root == null)
        return sum;

    stack.push(root);

        Node node = stack.pop();

Maximum valueEasy

Input: build(5, 12, 3, 7, 41, 2)

Output: 41

In a general binary tree, the maximum can be anywhere, so every node is examined. For an empty tree, both versions return Integer.MIN_VALUE.

Time O(n). Extra space O(w) iterative, O(h) recursive.

Iterative
public int treeMax(Node root) {
    int max = Integer.MIN_VALUE;
    if (root == null)
        return max;
    var stack = new ArrayDeque<Node>();
    stack.push(root);
    while (!stack.isEmpty()) {
        Node node = stack.pop();
        max = Math.max(max, node.data);
        if (node.left != null)
            stack.push(node.left);
        if (node.right != null)
            stack.push(node.right);
    }
    return max;
}
Recursive
public int treeMax(Node root) {
    if (root == null)
        return Integer.MIN_VALUE;
    int childMax = Math.max(treeMax(root.left), treeMax(root.right));
    return Math.max(root.data, childMax);
}
Search for a valueEasy

Input: the sample tree, key = 60

Output: true

Stop as soon as the key is found. In the recursive version, || short-circuits, so the right subtree is not searched when the left one already contains the key.

Time O(n) worst case. Extra space O(w) iterative, O(h) recursive.

Iterative
public boolean contains(Node root, int key) {
    if (root == null)
        return false;
    var queue = new ArrayDeque<Node>();
    queue.offer(root);
    while (!queue.isEmpty()) {
        Node node = queue.poll();
        if (node.data == key)
            return true;
        if (node.left != null)
            queue.offer(node.left);
        if (node.right != null)
            queue.offer(node.right);
    }
    return false;
}
Recursive
public boolean contains(Node root, int key) {
    if (root == null)
        return false;
    if (root.data == key)
        return true;
    return contains(root.left, key) || contains(root.right, key);
}
Count leaf nodesEasy

Input: build(1, 2, 3, 4, null, 5, 6)

Output: 3 (the leaves are 4, 5, 6)

A leaf is a node with no children.

Time O(n). Extra space O(w) iterative, O(h) recursive.

Iterative
public int countLeaves(Node root) {
    int leaves = 0;
    if (root == null)
        return leaves;
    var stack = new ArrayDeque<Node>();
    stack.push(root);
    while (!stack.isEmpty()) {
        Node node = stack.pop();
        if (node.left == null && node.right == null)
            leaves++;
        if (node.left != null)
            stack.push(node.left);
        if (node.right != null)
            stack.push(node.right);
    }
    return leaves;
}
Recursive
public int countLeaves(Node root) {
    if (root == null)
        return 0;
    if (root.left == null && root.right == null)
        return 1;
    return countLeaves(root.left) + countLeaves(root.right);
}
Invert a tree (LeetCode 226)Easy

Input: the sample tree

Output: its mirror image, level order [[40], [70, 20], [90, 60, 30, 10]]

Swap the left and right child of every node. The order of visits does not matter, so breadth-first search works as well as recursion.

The recursive version inverts both subtrees first (bottom-up), then swaps them.

Time O(n). Extra space O(w) iterative, O(h) recursive.

Iterative
public Node invert(Node root) {
    if (root == null)
        return null;
    var queue = new ArrayDeque<Node>();
    queue.offer(root);
    while (!queue.isEmpty()) {
        Node node = queue.poll();
        Node saved = node.left;
        node.left = node.right;
        node.right = saved;
        if (node.left != null)
            queue.offer(node.left);
        if (node.right != null)
            queue.offer(node.right);
    }
    return root;
}
Recursive
public Node invert(Node root) {
    if (root == null)
        return null;
    Node saved = invert(root.left);
    root.left = invert(root.right);
    root.right = saved;
    return root;
}
Same tree (LeetCode 100)Easy

Input: two trees built from [1, 2, 3]

Output: true

Two trees are the same when they have the same shape and equal values in matching positions.

Compare the nodes in pairs. Two nulls match; one null, or two different values, do not.

Time O(n). Extra space O(w) iterative, O(h) recursive.

Iterative
public boolean sameTree(Node a, Node b) {
    var queue = new ArrayDeque<Node[]>();
    queue.offer(new Node[] {a, b});
    while (!queue.isEmpty()) {
        Node[] pair = queue.poll();
        Node x = pair[0], y = pair[1];
        if (x == null && y == null)
            continue;
        if (x == null || y == null || x.data != y.data)
            return false;
        queue.offer(new Node[] {x.left, y.left});
        queue.offer(new Node[] {x.right, y.right});
    }
    return true;
}
Recursive
public boolean sameTree(Node a, Node b) {
    if (a == null || b == null)
        return a == b;
    return a.data == b.data && sameTree(a.left, b.left) && sameTree(a.right, b.right);
}
Symmetric tree (LeetCode 101)Easy

Input: build(1, 2, 2, 3, 4, 4, 3)

Output: true

A tree is symmetric when its left subtree is the mirror of its right subtree. Compare pairs as in "Same tree", but cross over: left.left pairs with right.right, and left.right pairs with right.left.

Time O(n). Extra space O(w) iterative, O(h) recursive.

Iterative
public boolean symmetric(Node root) {
    if (root == null)
        return true;
    var queue = new ArrayDeque<Node[]>();
    queue.offer(new Node[] {root.left, root.right});
    while (!queue.isEmpty()) {
        Node[] pair = queue.poll();
        Node x = pair[0], y = pair[1];
        if (x == null && y == null)
            continue;
        if (x == null || y == null || x.data != y.data)
            return false;
        queue.offer(new Node[] {x.left, y.right});
        queue.offer(new Node[] {x.right, y.left});
    }
    return true;
}
Recursive
public boolean symmetric(Node root) {
    return root == null || mirror(root.left, root.right);
}

public boolean mirror(Node a, Node b) {
    if (a == null || b == null)
        return a == b;
    return a.data == b.data && mirror(a.left, b.right) && mirror(a.right, b.left);
}
Left and right view (LeetCode 199)Easy

Input: build(1, 2, 3, null, 5, null, 4)

Output: left view [1, 2, 5], right view [1, 3, 4]

The left view is the first node of every level, and the right view is the last.

Iterative: breadth-first search level by level, keeping index 0 or index count - 1 of each level.

Recursive: depth-first search that records a node the first time its depth is reached. Visiting left first gives the left view; visiting right first gives the right view.

Time O(n). Extra space O(w) iterative, O(h) recursive.

Iterative
public List<Integer> leftView(Node root) {
    var view = new ArrayList<Integer>();
    if (root == null)
        return view;
    var queue = new ArrayDeque<Node>();
    queue.offer(root);
    while (!queue.isEmpty()) {
        int count = queue.size();
        for (int i = 0; i < count; i++) {
            Node node = queue.poll();
            if (i == 0)
                view.add(node.data);
            if (node.left != null)
                queue.offer(node.left);
            if (node.right != null)
                queue.offer(node.right);
        }
    }
    return view;
}

public List<Integer> rightView(Node root) {
    var view = new ArrayList<Integer>();
    if (root == null)
        return view;
    var queue = new ArrayDeque<Node>();
    queue.offer(root);
    while (!queue.isEmpty()) {
        int count = queue.size();
        for (int i = 0; i < count; i++) {
            Node node = queue.poll();
            if (i == count - 1)
                view.add(node.data);
            if (node.left != null)
                queue.offer(node.left);
            if (node.right != null)
                queue.offer(node.right);
        }
    }
    return view;
}
Recursive
public List<Integer> leftView(Node root) {
    var view = new ArrayList<Integer>();
    leftView(root, 0, view);
    return view;
}

public void leftView(Node node, int depth, List<Integer> view) {
    if (node == null)
        return;
    if (depth == view.size())
        view.add(node.data);
    leftView(node.left, depth + 1, view);
    leftView(node.right, depth + 1, view);
}

public List<Integer> rightView(Node root) {
    var view = new ArrayList<Integer>();
    rightView(root, 0, view);
    return view;
}

public void rightView(Node node, int depth, List<Integer> view) {
    if (node == null)
        return;
    if (depth == view.size())
        view.add(node.data);
    rightView(node.right, depth + 1, view);
    rightView(node.left, depth + 1, view);
}
Sum of each levelEasy

Input: the sample tree

Output: [40, 90, 190]

Entry i of the result is the sum of the nodes at depth i.

The recursive version opens a new entry the first time a depth is reached and adds each node to its depth's entry.

Time O(n). Extra space O(w) iterative, O(h) recursive.

Iterative
public List<Integer> levelSums(Node root) {
    var sums = new ArrayList<Integer>();
    if (root == null)
        return sums;
    var queue = new ArrayDeque<Node>();
    queue.offer(root);
    while (!queue.isEmpty()) {
        int sum = 0;
        for (int count = queue.size(); count > 0; count--) {
            Node node = queue.poll();
            sum += node.data;
            if (node.left != null)
                queue.offer(node.left);
            if (node.right != null)
                queue.offer(node.right);
        }
        sums.add(sum);
    }
    return sums;
}
Recursive
public List<Integer> levelSums(Node root) {
    var sums = new ArrayList<Integer>();
    levelSums(root, 0, sums);
    return sums;
}

public void levelSums(Node node, int depth, List<Integer> sums) {
    if (node == null)
        return;
    if (depth == sums.size())
        sums.add(0);
    sums.set(depth, sums.get(depth) + node.data);
    levelSums(node.left, depth + 1, sums);
    levelSums(node.right, depth + 1, sums);
}
Sum of left leaves (LeetCode 404)Easy

Input: build(3, 9, 20, null, null, 15, 7)

Output: 24 (the left leaves are 9 and 15)

A left leaf is a leaf that is the left child of its parent. A node cannot tell on its own which side it hangs on, so:

  • the iterative version checks node.left from the parent;
  • the recursive version passes an isLeft flag down.

Time O(n). Extra space O(w) iterative, O(h) recursive.

Iterative
public int leftLeavesSum(Node root) {
    int sum = 0;
    if (root == null)
        return sum;
    var stack = new ArrayDeque<Node>();
    stack.push(root);
    while (!stack.isEmpty()) {
        Node node = stack.pop();
        Node left = node.left;
        if (left != null && left.left == null && left.right == null)
            sum += left.data;
        else if (left != null)
            stack.push(left);
        if (node.right != null)
            stack.push(node.right);
    }
    return sum;
}
Recursive
public int leftLeavesSum(Node root) {
    return leftLeavesSum(root, false);
}

public int leftLeavesSum(Node node, boolean isLeft) {
    if (node == null)
        return 0;
    if (isLeft && node.left == null && node.right == null)
        return node.data;
    return leftLeavesSum(node.left, true) + leftLeavesSum(node.right, false);
}
Root-to-leaf path sum (LeetCode 112)Easy

Input: the sample tree, target = 90

Output: true (the path 40 → 20 → 30)

The path must end at a leaf; stopping at an inner node whose running sum matches does not count.

Iterative: depth-first search that pushes each node together with the sum of the path that reaches it.

Recursive: subtract the node's value from the target and ask the children for the remainder.

Time O(n). Extra space O(h).

Iterative
public boolean hasPathSum(Node root, int target) {
    if (root == null)
        return false;
    var nodes = new ArrayDeque<Node>();
    var sums = new ArrayDeque<Integer>();
    nodes.push(root);
    sums.push(root.data);
    while (!nodes.isEmpty()) {
        Node node = nodes.pop();
        int sum = sums.pop();
        if (node.left == null && node.right == null && sum == target)
            return true;
        if (node.right != null) {
            nodes.push(node.right);
            sums.push(sum + node.right.data);
        }
        if (node.left != null) {
            nodes.push(node.left);
            sums.push(sum + node.left.data);
        }
    }
    return false;
}
Recursive
public boolean hasPathSum(Node root, int target) {
    if (root == null)
        return false;
    if (root.left == null && root.right == null)
        return root.data == target;
    int rest = target - root.data;

Diameter of a tree (LeetCode 543)Easy

Input: the sample tree

Output: 4 (for example 10 → 20 → 40 → 70 → 90)

The diameter is the number of edges on the longest path between any two nodes. The path does not have to pass through the root.

The longest path that turns at a node has length height(left) + height(right). Computing heights separately for every node costs O(n2). Instead, compute each height once, bottom-up, and update the best answer on the way.

The iterative version is the one-stack postorder traversal, with a map holding each finished node's height.

Time O(n). Extra space O(n) iterative (map), O(h) recursive.

Iterative
public int diameter(Node root) {
    var height = new HashMap<Node, Integer>();
    var stack = new ArrayDeque<Node>();
    Node curr = root, prev = null;
    int best = 0;
    while (curr != null || !stack.isEmpty()) {
        if (curr != null) {
            stack.push(curr);
            curr = curr.left;
        } else if (stack.peek().right != null && stack.peek().right != prev) {
            curr = stack.peek().right;
        } else {
            Node node = stack.pop();
            int left = height.getOrDefault(node.left, 0);
            int right = height.getOrDefault(node.right, 0);
            best = Math.max(best, left + right);
            height.put(node, 1 + Math.max(left, right));
            prev = node;
        }
    }
    return best;
}
Recursive
public int diameter(Node root) {
    var best = new int[1];
    depth(root, best);
    return best[0];
}

public int depth(Node node, int[] best) {
    if (node == null)
        return 0;
    int left = depth(node.left, best);
    int right = depth(node.right, best);
    best[0] = Math.max(best[0], left + right);
    return 1 + Math.max(left, right);
}

Input: the sample tree / build(1, 2, null, 3)

Output: true / false

A tree is height-balanced when, at every node, the heights of the two subtrees differ by at most 1.

The recursive version returns -1 as soon as a subtree is unbalanced, so the answer is found in one bottom-up pass. The iterative version runs the same check during a postorder traversal.

Time O(n). Extra space O(n) iterative (map), O(h) recursive.

Iterative
public boolean balanced(Node root) {
    var height = new HashMap<Node, Integer>();
    var stack = new ArrayDeque<Node>();
    Node curr = root, prev = null;
    while (curr != null || !stack.isEmpty()) {
        if (curr != null) {
            stack.push(curr);
            curr = curr.left;
        } else if (stack.peek().right != null && stack.peek().right != prev) {
            curr = stack.peek().right;
        } else {
            Node node = stack.pop();
            int left = height.getOrDefault(node.left, 0);
            int right = height.getOrDefault(node.right, 0);
            if (Math.abs(left - right) > 1)
                return false;
            height.put(node, 1 + Math.max(left, right));
            prev = node;
        }
    }
    return true;
}
Recursive
public boolean balanced(Node root) {
    return checkedHeight(root) != -1;
}

// Height of the subtree, or -1 if any part of it is unbalanced.
public int checkedHeight(Node node) {
    if (node == null)
        return 0;
    int left = checkedHeight(node.left);
    if (left == -1)
        return -1;
    int right = checkedHeight(node.right);
    if (right == -1 || Math.abs(left - right) > 1)
        return -1;
    return 1 + Math.max(left, right);
}
Path from the root to a nodeMedium

Input: the sample tree, key = 60

Output: [40, 70, 60]

Iterative: breadth-first search that records each node's parent. Once the key is found, follow the parents back to the root and reverse the result.

Recursive (backtracking): add the node to the path. If neither the node nor its subtrees hold the key, remove it again.

Both versions return an empty list when the key is absent.

Time O(n). Extra space O(n) iterative, O(h) recursive.

Iterative
public List<Integer> pathTo(Node root, int key) {
    var parent = new HashMap<Node, Node>();
    var queue = new ArrayDeque<Node>();
    Node target = null;
    if (root != null)
        queue.offer(root);
    while (!queue.isEmpty()) {
        Node node = queue.poll();
        if (node.data == key) {
            target = node;
            break;
        }
        if (node.left != null) {
            parent.put(node.left, node);
            queue.offer(node.left);
        }
        if (node.right != null) {
            parent.put(node.right, node);
            queue.offer(node.right);
        }
    }
    var path = new ArrayList<Integer>();
    for (Node node = target; node != null; node = parent.get(node))
        path.add(node.data);
    Collections.reverse(path);
    return path;
}
Recursive
public List<Integer> pathTo(Node root, int key) {
    var path = new ArrayList<Integer>();
    pathTo(root, key, path);
    return path;
}

public boolean pathTo(Node node, int key, List<Integer> path) {
    if (node == null)
        return false;
    path.add(node.data);
    if (node.data == key || pathTo(node.left, key, path) || pathTo(node.right, key, path))
        return true;
    path.remove(path.size() - 1);
    return false;
}

Input: build(40, 20, 70, 10, 30, 60, 90) / build(40, 20, 70, 10, 50)

Output: true / false

In a BST, every value in the left subtree is smaller than the node and every value in the right subtree is larger.

Iterative: an inorder traversal of a BST is strictly increasing, so compare each value with the previous one.

Recursive: pass down the open interval (low, high) that the subtree's values must fall in. Using long bounds means Integer.MIN_VALUE and Integer.MAX_VALUE are still valid node values.

Iterative
public boolean isBST(Node root) {
    var stack = new ArrayDeque<Node>();
    Node curr = root;
    Integer prev = null;
    while (curr != null || !stack.isEmpty()) {
        while (curr != null) {
            stack.push(curr);
            curr = curr.left;
        }
        curr = stack.pop();
        if (prev != null && curr.data <= prev)
            return false;
        prev = curr.data;
        curr = curr.right;
    }
    return true;
}
Recursive
public boolean isBST(Node root) {

}

public boolean isBST(Node node, long low, long high) {

        return true;
    if (node.data <= low || node.data >= high)

Lowest common ancestor (LeetCode 236)Medium

Input: the sample tree, a = 10, b = 30

Output: 20

The lowest common ancestor is the deepest node that has both a and b as descendants. A node counts as its own descendant.

Both values are assumed to be present.

Iterative: record parents with breadth-first search until both nodes are found. Collect all ancestors of a, then climb from b until reaching one of them.

Recursive: a subtree returns whichever of the two values it contains. If the left and right subtrees both return something, the current node is where the two paths meet.

Time O(n). Extra space O(n) iterative, O(h) recursive.

Iterative
public Node lca(Node root, int a, int b) {
    var parent = new HashMap<Node, Node>();
    var queue = new ArrayDeque<Node>();
    Node nodeA = null, nodeB = null;
    queue.offer(root);
    while (nodeA == null || nodeB == null) {
        Node node = queue.poll();
        if (node.data == a)
            nodeA = node;
        if (node.data == b)
            nodeB = node;
        if (node.left != null) {
            parent.put(node.left, node);
            queue.offer(node.left);
        }
        if (node.right != null) {
            parent.put(node.right, node);
            queue.offer(node.right);
        }
    }
    var ancestors = new HashSet<Node>();
    for (Node node = nodeA; node != null; node = parent.get(node))
        ancestors.add(node);
    Node node = nodeB;
    while (!ancestors.contains(node))
        node = parent.get(node);
    return node;
}
Recursive
public Node lca(Node node, int a, int b) {
    if (node == null || node.data == a || node.data == b)
        return node;
    Node left = lca(node.left, a, b);
    Node right = lca(node.right, a, b);
    if (left != null && right != null)
        return node;
    return left != null ? left : right;
}
Zigzag level order (LeetCode 103)Medium

Input: the sample tree

Output: [[40], [70, 20], [10, 30, 60, 90]]

Levels alternate direction: left to right, then right to left, and so on.

The traversal itself is an ordinary level order. Only the insertion point changes: append on even levels, prepend on odd ones. A LinkedList makes both O(1).

Time O(n). Extra space O(w) iterative, O(h) recursive.

Iterative
public List<List<Integer>> zigzag(Node root) {
    var result = new ArrayList<List<Integer>>();
    if (root == null)
        return result;
    var queue = new ArrayDeque<Node>();
    queue.offer(root);
    boolean leftToRight = true;
    while (!queue.isEmpty()) {
        var level = new LinkedList<Integer>();
        for (int count = queue.size(); count > 0; count--) {
            Node node = queue.poll();
            if (leftToRight)
                level.addLast(node.data);
            else
                level.addFirst(node.data);
            if (node.left != null)
                queue.offer(node.left);
            if (node.right != null)
                queue.offer(node.right);
        }
        result.add(level);
        leftToRight = !leftToRight;
    }
    return result;
}
Recursive
public List<List<Integer>> zigzag(Node root) {
    var result = new ArrayList<List<Integer>>();
    zigzag(root, 0, result);
    return result;
}

public void zigzag(Node node, int depth, List<List<Integer>> result) {
    if (node == null)
        return;
    if (depth == result.size())
        result.add(new LinkedList<>());
    if (depth % 2 == 0)
        result.get(depth).add(node.data);
    else
        result.get(depth).add(0, node.data);
    zigzag(node.left, depth + 1, result);
    zigzag(node.right, depth + 1, result);
}
Build a tree from preorder and inorder (LeetCode 105)Medium

Input: preorder = [40, 20, 10, 30, 70, 60, 90], inorder = [10, 20, 30, 40, 60, 70, 90]

Output: the sample tree (postorder [10, 30, 20, 60, 90, 70, 40])

Values must be distinct.

Recursive: the next preorder value is the root of the current subtree. Its position in the inorder array splits that array into the left subtree and the right subtree. A hash map gives the position in O(1).

Iterative: keep a stack of nodes still waiting for a right child, and push each new preorder value as a left child. When the stack top equals the next inorder value, that node's left side is complete. Pop such nodes; the new value becomes the right child of the last one popped.

Time O(n). Extra space O(n).

Iterative
public Node fromTraversals(int[] preorder, int[] inorder) {
    if (preorder.length == 0)
        return null;
    var root = new Node(preorder[0]);
    var stack = new ArrayDeque<Node>();
    stack.push(root);
    int in = 0;
    for (int i = 1; i < preorder.length; i++) {
        var node = new Node(preorder[i]);
        Node parent = stack.peek();
        if (parent.data != inorder[in]) {
            parent.left = node;
        } else {
            while (!stack.isEmpty() && stack.peek().data == inorder[in]) {
                parent = stack.pop();
                in++;
            }
            parent.right = node;
        }
        stack.push(node);
    }
    return root;
}
Recursive
public Node fromTraversals(int[] preorder, int[] inorder) {
    var position = new HashMap<Integer, Integer>();
    for (int i = 0; i < inorder.length; i++)
        position.put(inorder[i], i);
    var next = new int[1];
    return subtree(preorder, next, 0, inorder.length - 1, position);
}

public Node subtree(int[] preorder, int[] next, int lo, int hi, Map<Integer, Integer> position) {
    if (lo > hi)
        return null;
    var node = new Node(preorder[next[0]++]);
    int mid = position.get(node.data);
    node.left = subtree(preorder, next, lo, mid - 1, position);
    node.right = subtree(preorder, next, mid + 1, hi, position);
    return node;
}
Flatten a tree to a linked list (LeetCode 114)Medium

Input: the sample tree

Output: a right-leaning chain in preorder: 40 → 20 → 10 → 30 → 70 → 60 → 90, with every left set to null.

Iterative, O(1) space: at each node that has a left subtree, find that subtree's rightmost node. Hang the current right subtree there, move the left subtree to the right, and continue down the right.

Recursive: flatten both subtrees, then splice the left chain between the node and the right chain. The method returns the tail of the flattened chain so that the splice is O(1).

Time O(n). Extra space O(1) iterative, O(h) recursive.

Iterative
public void flatten(Node root) {
    Node curr = root;
    while (curr != null) {
        if (curr.left != null) {
            Node last = curr.left;
            while (last.right != null)
                last = last.right;
            last.right = curr.right;
            curr.right = curr.left;
            curr.left = null;
        }
        curr = curr.right;
    }
}
Recursive
// Flattens the subtree and returns the last node of the chain.
public Node flatten(Node node) {
    if (node == null)
        return null;
    Node leftTail = flatten(node.left);
    Node rightTail = flatten(node.right);
    if (leftTail != null) {
        leftTail.right = node.right;
        node.right = node.left;
        node.left = null;
    }
    if (rightTail != null)
        return rightTail;
    return leftTail != null ? leftTail : node;
}

Maximum path sum (LeetCode 124)Hard

Input: build(-10, 9, 20, null, null, 15, 7)

Output: 42 (the path 15 → 20 → 7)

A path may start and end at any nodes, but it can turn only once, at its highest node.

For every node, compute its gain: the best sum of a downward path starting there. Negative gains are dropped (treated as 0). The best path that turns at the node is then data + gain(left) + gain(right).

The iterative version computes the gains in a postorder traversal, exactly as in "Diameter".

Time O(n). Extra space O(n) iterative (map), O(h) recursive.

Iterative
public int maxPathSum(Node root) {
    var gain = new HashMap<Node, Integer>();
    var stack = new ArrayDeque<Node>();
    Node curr = root, prev = null;
    int best = Integer.MIN_VALUE;
    while (curr != null || !stack.isEmpty()) {
        if (curr != null) {
            stack.push(curr);
            curr = curr.left;
        } else if (stack.peek().right != null && stack.peek().right != prev) {
            curr = stack.peek().right;
        } else {
            Node node = stack.pop();
            int left = Math.max(0, gain.getOrDefault(node.left, 0));
            int right = Math.max(0, gain.getOrDefault(node.right, 0));
            best = Math.max(best, node.data + left + right);
            gain.put(node, node.data + Math.max(left, right));
            prev = node;
        }
    }
    return best;
}
Recursive
public int maxPathSum(Node root) {
    var best = new int[] {Integer.MIN_VALUE};
    gain(root, best);
    return best[0];
}

public int gain(Node node, int[] best) {
    if (node == null)
        return 0;
    int left = Math.max(0, gain(node.left, best));
    int right = Math.max(0, gain(node.right, best));
    best[0] = Math.max(best[0], node.data + left + right);
    return node.data + Math.max(left, right);
}

A traversal alone cannot identify a tree; writing # for every missing child makes it unambiguous. Each version below reads back exactly the format it writes.

Recursive (preorder): 40,20,10,#,#,30,#,#,70,60,#,#,90,#,#. Reading follows the same order: node, then its whole left subtree, then its whole right subtree.

public String serialize(Node root) {
    var out = new StringJoiner(",");
    var queue = new LinkedList<Node>();   // LinkedList accepts null
    queue.offer(root);
    while (!queue.isEmpty()) {
        Node node = queue.poll();
        if (node == null) {
            out.add("#");
            continue;
        }
        out.add(String.valueOf(node.data));
        queue.offer(node.left);
        queue.offer(node.right);
    }
    return out.toString();
